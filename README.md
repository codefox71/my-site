# Codefox's Digital Labs

A small personal website for experiments, simulations, and future browser-based lab projects.

## Pages

- `index.html` — the home page and digital labs directory
- `emerg.html` — the CEGL lab page with emergent, flocking, and cellular simulations

## Notes

- The home page is intentionally minimal and sterile in style.
- It links to current and future lab experiments.
- The CEGL page preserves the earlier emergent-life simulation work.
- A light/dark mode toggle is included on the home page and persists via `localStorage`.

## Local preview

Open `index.html` in a browser, or serve the folder with a simple local static server if preferred.
